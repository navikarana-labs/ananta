# Project Ananta

> [!WARNING]
> Work in progress!

**Distributed Fault-Tolerant Robotic System**

Project Ananta is a research and engineering project under [Navikarana Labs](https://navikarana.io), exploring distributed embedded control, fault detection, diagnosis, and safe recovery.

A tracked robotic rover will serve as the initial test platform.
